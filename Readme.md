> **Hotdrop** - это Telegram-тапалка с фармингом, обменом валюты, игровыми режимами, внутриигровым магазином, реферальной системой, прокачкой уровней, рейтингом, заданиями, открытием кейсов и многим другим.  
> Написана с использованием современных технологий: **React, TypeScript, Redux Toolkit, RTK Query** и кастомной сборки на **Webpack**.

---

## 🚀 Локальный запуск

Чтобы запустить проект локально:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/4min-dev/Hotdrop-bot.git

# 2. Перейдите в папку проекта
cd Hotdrop-bot

# 3. Установите зависимости
npm install

# 4. Запустите сервер разработки
npm run start
```
